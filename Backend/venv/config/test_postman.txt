========================================
        ACCOUNTS API TEST GUIDE
========================================

BASE URL:
http://127.0.0.1:8000/api/v1/accounts/

AUTH:
Bearer Token (JWT access token)
========================================


========================================
1. REGISTER API
========================================

POST /register/

Body (JSON):
{
    "username": "user1",
    "email": "user1@test.com",
    "password": "123456"
}

Response:
{
    "status": "success",
    "message": "Account created successfully"
}


========================================
2. LOGIN API
========================================

POST /login/

Body:
{
    "login": "user1 OR user1@test.com",
    "password": "123456"
}

Response:
{
    "status": "success",
    "data": {
        "access": "...",
        "refresh": "...",
        "user": {
            "id": 1,
            "username": "user1",
            "email": "user1@test.com",
            "role": "USER"
        }
    }
}


========================================
3. ME API
========================================

GET /me/

Headers:
Authorization: Bearer <access>

Response:
User profile data


========================================
4. LOGOUT API (single device)
========================================

POST /logout/

Headers:
Authorization: Bearer <access>

Body:
{
    "refresh": "<refresh_token>"
}

Response:
{
    "status": "success",
    "message": "Logged out successfully"
}


========================================
5. LOGOUT ALL DEVICES API
========================================

POST /logout-all/

Headers:
Authorization: Bearer <access>

Body: NONE

Response:
{
    "status": "success",
    "message": "Logged out from all devices"
}


========================================
6. CHANGE PASSWORD (LOGIN REQUIRED)
========================================

POST /change-password/

Headers:
Authorization: Bearer <access>

Body:
{
    "old_password": "123456",
    "new_password": "new123",
    "new_password2": "new123"
}

Response:
{
    "status": "success",
    "message": "Password changed successfully"
}


========================================
7. FORGOT PASSWORD (SEND OTP)
========================================

POST /forgot-password/

Body:
{
    "email": "user1@test.com"
}

Response:
{
    "status": "success",
    "message": "OTP sent successfully"
}


========================================
8. VERIFY OTP
========================================

POST /verify-otp/

Body:
{
    "email": "user1@test.com",
    "code": "123456"
}

Response:
{
    "status": "success",
    "message": "OTP verified"
}


========================================
9. RESET PASSWORD
========================================

POST /reset-password/

Body:
{
    "email": "user1@test.com",
    "code": "123456",
    "new_password": "new123"
}

Response:
{
    "status": "success",
    "message": "Password changed successfully"
}


========================================
ERROR RESPONSES FORMAT
========================================

400:
{
    "status": "error",
    "message": "Invalid request"
}

401:
{
    "detail": "Authentication credentials were not provided"
}

403:
{
    "status": "error",
    "message": "Forbidden"
}


========================================
JWT NOTES
========================================

ACCESS TOKEN:
- expires fast (minutes)

REFRESH TOKEN:
- used to generate new access token

IMPORTANT:
- After logout, refresh token becomes invalid (blacklisted)
